# PLAYER V7 Facts

Public, signed offline-facts release assets consumed by MACHINA PLAYER V7.

Each release will carry two stable assets:

- `facts.sqlite` — the read-only facts snapshot
- `facts-manifest.json` — version, size, SHA-256 digest, download URL, and Ed25519 signature

PLAYER verifies both the digest and signature before installation. Its pinned Ed25519 public key is
`+CoRC28C8MR3QCOY6pIeIOKZD365GCXeR5bfwwHGw9M=`.

No corpus has been published yet. Every release must state its source lineage and redistribution
license; incomplete staging databases and household-derived title selections do not belong here.
